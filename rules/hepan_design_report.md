# 紫微斗数合盘功能 — 设计报告

## 一、太极转换体系详解（合盘的理论基础）

### 1.1 物物一太极

紫全书原文核心思想（`rules_ziquan.md:212-220`）：

> 易经上说，太极就是气，就是一团混沌之气。
> 这张命盘也是个太极，里面就有**十二个小太极**。
> 命宫是一个太极，兄弟宫也是一个太极，夫妻宫也是一个太极……
> 这十二个小太极合起来就是一个**大太极**。

三层太极体系：

| 层级 | 含义 | 举例 |
|------|------|------|
| **大太极** | 整张命盘=我这个人 | 十二宫合体 |
| **中太极** | 任意两宫的关系 | 命+夫=禄 → 我与配偶伉俪情深 |
| **小太极** | 单一宫位=一个独立太极点 | 夫妻宫=配偶的命宫 |

### 1.2 宫位太极转换（借宫）

经诚压缩版（`rules_jingcheng_compact.md:232-236`）：

- 命宫为原太极；**任意宫均可作为新太极**（该宫主事之人的命宫）
- 以兄弟宫为太极 → 看兄弟命运
- 以夫妻宫为太极 → 看配偶命运
- 新太极点后的十二宫顺序同原命盘，吉凶判断方法相同
- 原命盘为**体**（我），新命盘为**用**（六亲）；两盘联动分析

解读书（`rules_jiedu.md:86-89`）补充：

- 我的兄弟宫 = 兄弟的命宫
- 兄弟的财帛宫 = 我的疾厄宫（顺数推算）
- **看任何六亲问题须先以该亲宫位为太极点重布十二宫，再看其三方四正**

### 1.3 为什么太极转换是合盘的理论基础？

单盘分析中，太极转换的用法是：**在我的命盘内部**，以某宫为太极点，重新定义十二宫，来分析该六亲的运势。

合盘中的延伸应用（进阶）：

| 单盘太极转换 | 合盘太极转换 |
|-------------|-------------|
| 在我的盘内，以夫妻宫为太极 → 看我盘中的配偶信息 | 将对方的实际命盘叠加 → 验证/补充我盘中的推论 |
| 只用我一个人的出生信息 | 需要两人的出生信息 |
| 看的是"我眼中的配偶" | 看的是"配偶真实的状态 + 双方互动" |

## 二、书中已找到的合婚规则

### 2.1 三合派合婚法（星情配对）

**来源**：`ch13_14_raw.txt:3560-3569`

以男女双方命盘的命宫与夫妻宫的**星情**来论合婚：

| 我的夫妻宫/命宫 | 适配对象的命宫/夫妻宫 | 评价 |
|-----------------|---------------------|------|
| 火星独守夫妻宫 | 擎羊星在命/夫妻宫 | **绝配** |
| 巨门在子午线 | 巨门在子午线 | 同病相怜，**绝配** |
| 巨门 | 天梁（大人星） | 堪称**美眷** |
| 巨门 | 太阳（光明之星） | 也不错 |
| 紫微独坐夫妻 | 太阳/天府/贪狼/天相/禄存坐命 | 佳配（+左右昌曲更佳） |

**实现思路**：比较甲方夫妻宫主星 vs 乙方命宫主星，查表匹配。

### 2.2 河洛派合婚法（四化飞星合盘）

**来源**：`ch13_14_raw.txt:3570-3581`

用**对方的生年干**在**我命盘上**飞四化：

| 对方生年干化曜落入我的宫位 | 结论 |
|---------------------------|------|
| 化三吉入我**三合方**（命、财、官） | 能使我格调高，给我助益 |
| 化吉入我**父疾线** | 对方为我的文书贵人 |
| 化吉入我**兄友线** | 助我事业成功 |
| 化吉入我**田宅、福德** | 佳配 |
| **化忌**入我**命迁线** | ❌ 必为怨偶，不可配 |
| **化忌**入我**财福线** | ❌ 必为怨偶，不可配 |
| 对方**命宫干**化禄入我**命/疾** | 对方对我感情深厚（入命尤佳） |

**实现思路**：
1. 取乙方生年天干 → 查十干四化表 → 得到化禄/权/科/忌对应的四颗星
2. 在甲方命盘中找到这四颗星所在的宫位
3. 判断这些宫位是否落入上表的关键线位
4. 双向执行（甲看乙 + 乙看甲）→ 综合评分

### 2.3 婚姻顺逆格局（补充）

**来源**：`ch13_14_raw.txt:3611-3614`

- 命化禄入夫妻 + 夫妻化禄入命 = **婚姻最佳**
- 命宫与夫妻四化中的三吉互系 = 婚姻较顺

## 三、书中尚未覆盖的合盘场景

| 合盘类型 | 书中覆盖情况 | 需要补充 |
|---------|-------------|---------|
| **婚姻合盘** | ✅ 三合派 + 河洛派 | 较完整 |
| **合作关系** | ❌ 无专门论述 | 需要：以官禄宫/交友宫为太极的飞星合盘规则 |
| **亲子关系** | ❌ 无专门论述 | 需要：以子女宫/父母宫为太极的飞星合盘规则 |
| **互看宫位** | ⚠️ 三合派仅涉及命宫/夫妻宫星情比较 | 需要系统化的十二宫互看规则 |

### 4.4 配色与视觉建议

| 元素 | 颜色 | 说明 |
|------|------|------|
| 甲方信息 | 蓝色系 | 与现有排盘主色一致 |
| 乙方信息 | 粉/红色系 | 镜像对称，视觉区分 |
| ✅ 吉象 | 绿色 | 化三吉入佳位 |
| ❌ 凶象 | 红色 | 化忌入命迁/财福线 |
| ⚠️ 中性 | 橙色 | 需注意但非绝对凶 |
| 星级评分 | 金色星星 | 直观总评 |
