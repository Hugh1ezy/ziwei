## 一、基础概念

### 1.1 十天干
顺序：甲乙丙丁戊己庚辛壬癸
- 阳干：甲丙戊庚壬
- 阴干：乙丁己辛癸
- 五行：甲乙木、丙丁火、戊己土、庚辛金、壬癸水

### 1.2 十二地支
顺序：子丑寅卯辰巳午未申酉戌亥
- 阳支：子寅辰午申戌
- 阴支：丑卯巳未酉亥
- 五行：寅卯木、巳午火、申酉金、子亥水、辰戌丑未土

## 二、排盘步骤

### 2.1 安命宫
**规则**：从寅宫起正月，顺时针方向数到出生月之宫止，再从该宫起子时，**逆时针**方向数到出生时支止，所在宫即为命宫。

**举例**：三月辰时生人
1. 从寅宫起正月，顺数：寅=正月，卯=二月，辰=三月 → 到辰宫
2. 从辰宫起子时，逆数：辰=子时，卯=丑时，寅=寅时，丑=卯时，子=辰时 → 到子宫
3. 命宫在子

### 2.2 安身宫
**规则**：从寅宫起正月，顺时针方向数到出生月之宫止，再从该宫起子时，**顺时针**方向数到出生时支止，所在宫即为身宫。

### 2.3 十二宫名称与顺序
从命宫起，**逆时针**方向依次排列：
1. 命宫
2. 兄弟宫
3. 夫妻宫
4. 子女宫
5. 财帛宫
6. 疾厄宫
7. 迁移宫
8. 奴仆宫（交友宫）
9. 官禄宫（事业宫）
10. 田宅宫
11. 福德宫
12. 父母宫

### 2.5 定命宫五行局
以命宫天干和地支查纳音五行，纳音五行即为五行局：

**纳音五行速记法**：
- 天干配数：甲乙=1，丙丁=2，**戊己=3，庚辛=4**，壬癸=5
- 地支配数：子丑午未=1，寅卯申酉=2，辰巳戌亥=3
- 干数+支数=和数（若>5 则减5），查对应五行：
  1=木，2=金，3=水，4=火，5=土

> ⚠️ 注：原书提取文本（字全书_extracted.txt 约第129行）印刷有误，写为"庚辛3，戊己4"，但
> 据同书六十甲子纳音表（戊子己丑=霹雳火→火，庚午辛未=路旁土→土）可验证正确顺序为
> 戊己=3，庚辛=4。程序以此正确值实现。

**五行局对应**：

### 3.2 公式法
设农历出生日数为 A，五行局数为 B：
1. 求最小非负整数 X，使 (A+X) 能被 B 整除
2. C = (A+X) / B
3. 若 X 为偶数：D = C + X；若 X 为奇数：D = C - X（若结果≤0 则加12）
4. D 对应宫位：寅=1，卯=2，辰=3，巳=4，午=5，未=6，申=7，酉=8，戌=9，亥=10，子=11，丑=12

## 十八、斗君与流月 ✅已实现

> 原书（行1620-1625）：
> "斗君即是流月的正月。因是以各人的生月和生时为准来推出的，所以各人的斗君不同，且每年不同。"

- **斗君宫（流年Y）**：

  2. 从L起正月，逆数到出生月：月宫 = `(L - (出生月 - 1) + 12) % 12`
  3. 从月宫起子时，顺数到出生时辰：斗君 = `(月宫 + 出生时辰支索引) % 12`

  - 每年递增1宫：`斗君(Y) = (生年斗君 + Y - 出生农历年) % 12`

- **流月M**：`(斗君宫 + M - 1) % 12`（正月=斗君宫，顺盘布月）

## 二十一、旬空星（修正）

> 原书第28步（行1611-1613）：
> "速记法：在指掌上生年支的位置加上生年干，然后从该支上起逆数天干至甲止，所止之宫即为六甲旬头，再以旬头推旬空星，在旬头地支退后的二个地支就是旬空星。例如，甲子旬，退后两个地支就是戍亥，故甲子旬中戍亥空。"

- **六甲旬头查法**：
  - 60甲子中，年干支所在旬的旬头（旬头天干=甲），旬头地支决定旬空
  - 年干支 → 年干支在甲子(0)起的序号N = `(yearStemIdx * 12 + yearBrIdx) % 60`
  - 旬头序号 = `N - (N % 10)` → 旬头地支 = `旬头序号 % 12`
  - 旬空 = `(旬头地支 - 1 + 12) % 12` 和 `(旬头地支 - 2 + 12) % 12`
- **正确公式**（✅已实现）：
  1. `s = ((yearStemIdx - yearBrIdx) % 10 + 10) % 10`（s 必为偶数）
  2. `t = s / 2`
  3. `n = yearBrIdx + 12 * t`（60甲子中的真实序号）
  4. 旬头序号 = `n - (n % 10)`，旬头地支 = `旬头序号 % 12`
  5. 旬空 = 旬头地支 -1 和 -2（mod 12）
- **注**：截空（§9，书第13步）与旬空（本节，书第28步）是两颗**不同的星**，均已实现：
  - 截空：仅由年干决定，按年干配固定两地支（JIEKONG_MAP）✅
  - 旬空：由年干支共同决定，按六甲旬头推算（getXunKong）✅
