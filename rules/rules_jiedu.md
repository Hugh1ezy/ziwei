## 第一章 核心术语

- **正星14颗**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军
- **六吉星**：左辅、右弼、天魁、天钺、文昌、文曲；加禄存、天马为八吉
- **四煞**：擎羊、陀罗、火星、铃星；加天空、地劫为六煞
- **四化**：化禄（吉/财）、化权（权/竞争）、化科（名/贵人）、化忌（凶/损耗）
- **三方四正**：本宫+三合两宫+对冲宫，论命主线
- **朝/冲**：吉星居对宫=朝，凶/化忌在对宫=冲
- **辅/夹**：吉星分居两邻宫=辅，凶星夹=夹
- **庙旺得陷**：庙>旺>得>陷，庙旺充分发挥，陷落无力
- **四恶曜**：杀破廉贪，失陷遇煞大凶，入庙反具横发力
- **杀破狼**：永远三合会照，限年逢之主变革开创
- **天罗地网**：辰宫（天罗）、戌宫（地网），捆绑之象；辰戌生人逢本宫岁限尤忌
- **本对合邻力量**（来源：《初级讲义》）：本宫60%、对宫40%、合宫（三合）20%、邻宫10%
- **《十喻歌》**：本方吉=自强，凶=自伐；对方吉=春风，凶=恶棒；合方吉=逢源，凶=受敌；邻方吉=相扶，凶=相侮
- **身宫落宫效果**：命身同宫=性格明显内外一致；身入夫妻=特别在意感情；身入财帛=重财不重名；身入迁移=喜出外易转工搬家；身入事业=事业心重；身入福德=重享受生活品味
- ★身宫从出生即起作用（非坊间所说30岁后才起作用），只是随年龄增大越来越明显（来源：《内部讲义》）
- 命宫=抓什么牌，身宫=怎么出牌；身宫所处宫气越弱人生越折腾
- **解盘三原则**（来源：《内部讲义》）：宫定环境、星定本质、干定来由（宫/星/干各占象三分之一）
- **八宫概念**：看任何宫位须同时看本宫三方四正+对宫三方四正共八宫；立极不忘起初，所有分析回归命宫

### 1.x 十二长生宫气（来源：《内部讲义》古法）

- ★五行局决定十二长生起始：金长生巳、木长生亥、火长生寅、水土长生申
- 方向与大限一致（阳男阴女顺，阴男阳女逆）
- 旺气序：长生→沐浴→冠带→临官→帝旺（渐旺）；衰→病→死→墓→绝（渐弱）；胎→养（有生机）
- ★弱气≠凶，旺气≠吉，是星运行的环境；弱气主浮动波动大多败少成，旺气主稳定
- 墓绝虽弱但离旺气最近有生机；帝旺过后"风雪将至"

### 1.2 太微赋纲领（来源：《全书》卷一）

- ★紫微天府全依辅弼之功，七杀破军专依羊铃之虐
- ★诸星吉逢凶也吉，诸星凶逢凶也凶
- ★主强宾弱可保无虞，主弱宾强凶危立见（主星vs客星力量原则）
- ★禄逢冲破吉处藏凶，马遇空亡终身奔走
- ★生逢败地发也虚花，绝处逢生花而不败
- ★日月守不如照合，荫福聚不怕凶危
- ★辅弼夹帝为上品，桃花犯主为至淫
- ★殺居絕地天年夭似顏回，贪坐生鄉壽考永如彭祖
- 片火焚天马，重羊逐禄存（火星克天马；擎羊克禄存）
- 前后两凶神为两邻，加会尚可撑持，同室与谋最难堤防（夹比同宫伤害大）

### 1.3 骨髓赋要诀（来源：《全书》卷一）

- ★命无正曜夭折孤贫（命宫无正星=大凶，须借对宫或财官吉星方可）
- ★七杀破军宜出外，机月同梁作吏人（古赋限定命在寅申方论）
- ★廉贞七杀反为积富之人（经典反格）
- ★先贫后富武贪同身命之宫（武贪同守先贫后富）
- 巨机同宫公卿之位，贪铃并守将相之名
- 铃昌罗武限至投河（铃+文昌+陀罗+武曲限年=大凶）
- 巨火擎羊终身缢死（巨门+火星+擎羊=缢死凶格）
- 天梁遇马女命贱而且淫
- 天机天梁擎羊会早有刑而晚见孤
- 贪狼武曲廉贞逢少受贫而后享福
- 夹贵夹禄夹权夹科=吉；夹空夹劫=贫贱，夹羊夹陀=乞丐
- 心好命微亦主寿，心毒命固亦夭亡

## 第二章 十二宫含义

| 宫位 | 核心含义 |
|------|---------|
| 命宫 | 个性、才华、格局高低、运势起伏、相貌 |
| 兄弟 | 兄弟缘分厚薄；私人机构、直销传销 |
| 夫妻 | 配偶个性才华家世、婚姻观、姻缘类型；隐含性=财帛宫的夫妻位 |

| 财帛 | 理财能力、赚钱机会、财的来龙去脉 |
| 疾厄 | 健康体质、疾病灾厄；意识形态、脾气、心术正邪 |
| 迁移 | 外出变迁运、人生机遇、贵人运、老运走势 |
| 奴仆 | 交友缘分、部属助力；众生相、绝情宫、寿元关键宫 |
| 官禄 | 运势起伏（气数宫）、事业状态、学业考运、功名官运 |
| 田宅 | 祖业不动产、住宅环境、家运、库位 |
| 福德 | 福气道德、享福应酬、身心健康、因果位、造化宫 |

> 福德弱气特征（《内部讲义》）：前三限冲动任性博而不专（疾宫旺在撑），三限后前期挥霍显现；化解：通风向阳、多外出走动、阴以阳解
| 父母 | 父母格局、长上缘分；文书宫、相貌宫、头脑智商 |

### 2.1b 借宫与六亲对待（来源：《命运分析》涂曾生Ch8）
- **紫微斗数的借宫**：每一宫位可以转化为其他人的命宫来分析（我的兄弟宫=兄弟的命宫，兄弟的财帛宫=我的疾厄宫，以此类推）
- 六亲对待宫位：从任何宫位起，顺数第N宫即为该人的第N宫（如从兄弟起数第二宫=兄弟的夫妻宫=我的夫妻宫）
- 成功条件图（来源：《命运分析》Ch8）：成功=自我行动力（命宫）+福德事业（三合）+综合力（六亲）
- ★看任何六亲问题须先以该亲宫位为太极点重布十二宫，再看其三方四正

### 2.2 本对宫强弱互补（来源：《内部讲义》）
- ★本宫与对宫必定一强一弱（以十二长生宫气定），十二宫皆如此
- 命弱迁旺=适合外出发展；命旺迁弱=外出后受命宫旺气正面辅助
- 财旺福弱=来财机会多但抓不住；福旺财弱=机会少但能把握
- 夫旺官弱/官旺夫弱=事业与婚姻很难同时美满
- 子旺田弱=注意怀孕期/流产/家宅不安；田旺子弱=注意子女教育
- 疾旺父弱=承载力强但父辈弱/遗传病可能；父旺疾弱=长辈荫庇但自身承载差

### 2.3 六合宫融合（来源：《内部讲义》古法）
- ★地支六合（子丑、寅亥、卯戌、辰酉、巳申、午未）导致对应宫位力量融合
- 六合宫弱气方为主导（弱气方为问题根源）
- 疾福六合=先天耗神，精神与身体互相拖累；戊癸入=因情耗神，甲廉贞入=因事业耗神
- 夫父六合=婚姻感情受父母影响（父弱=阻力压力）
- 兄夫六合弱气见桃花=闺蜜/朋友抢配偶
- 疾官/疾夫六合=创业比例最高的组合
- 命田六合=根基与田宅融合，一动皆动，四海为家
- 子福六合精神宫弱=想要孩子又怕生孩子，教育不稳定

### 2.4 宫位特殊论断（来源：《全书》）
- ★父母宫日月论：太阳陷宫先克父，太阴陷宫先克母；二星俱陷日生主父存、夜生主母在
- ★子女宫生男生女：三方四正南斗多主生男，北斗多主生女；太阳阳宫先生男，太阴阴宫先生女
- 男命强宫：财帛、官禄、福德、迁移、田宅；弱宫：子女、奴仆、兄弟、父母
- 女命强宫：夫君、子息、财帛、田宅、福德

## 第三章 四化象

### 3.1 四化基本含义

**化禄**：财禄/食禄/福禄、人缘佳/异性缘、忙碌/好施舍、聪明/才艺、增加增多、解厄延寿；★恶曜来临并羊陀火忌冲照亦不为害（化禄解凶能力强）
**化权**：权势/威严、掌权/领导、任性/果决、能干/专技/开创、争执/外伤、增值；逢羊陀耗使劫空=官灾贬谪
**化科**：科甲/功名、声名/念旧、聪明/博学/才艺、平顺/计划、贵人/解厄、风度/桃花；★虽四杀冲破亦为富贵
**化忌**：变动/驿马/不安、收藏/收束、亏欠/固执/情谊、不顺/困扰/是非、凶兆/灾厄、缘薄

### 3.3 四化入宫简断

- ★禄入六亲宫→与该亲缘厚、借其力显彰；入财官→忙碌得财/事业有成
- ★权入六亲宫→该亲能干掌权、与之争执；入财→敢赚敢花；入官→掌权开创
- ★科入六亲宫→该亲聪明有风度、与之和睦、该亲为贵人；入官→求学顺利
- ★忌入六亲宫→对该亲亏欠、缘薄；入命→不顺/钻牛角尖/不宜创业；入财→辛苦守财不牢

### 3.4 生年四化（体）vs 飞宫四化（用）vs 自化（造化）

- **生年四化**：先天定数，命的本质，决定富贵贫贱之格
- **飞宫四化**：宫干飞出四化入他宫，动态吉凶，宫象星合一
- **自化**：宫干四化落回本宫，后天变数，有中化无/无中生有
- **视同自化**：宫干四化落入对宫，意义近自化，另含不断缘起

### 3.5 自化叠化规则

| 组合 | 效果 |
|------|------|
| 禄+自化禄 | 同类抵消=无禄 |
| 禄+自化忌 | 禄忌=双忌论 |
| 权+自化权 | 同类抵消=无权 |
| 权+自化忌 | 权可解忌，想做又不做 |
| 科+自化科 | 同类抵消=无科 |
| 科+自化忌 | 科可解忌但不彻底 |
| 忌+自化禄 | 禄忌=双忌 |
| 忌+自化忌 | 同类抵消=不忌 |

### 3.5b 化出与化入之别（来源：《命运分析》涂曾生Ch17）
- **他宫化入我宫**：别人的力量加持于我，外来助力或压力
- **我宫化出他宫**：我的力量投射于他，主动付出或损耗
- ★化入=接受、获得、被影响；化出=付出、给予、影响他人
- 化禄化入我宫=有人送财助力；化禄化出=我布施散财
- 化忌化入我宫=他人带来困扰；化忌化出=我给他人添麻烦

### 3.6 四化飞伏关键规则

- ★化忌入宫=引坏，化忌冲宫=真正破坏；一颗化忌牵动三宫（坐忌、冲宫、冲宫的三合）
- ★忌入六内宫=收藏得财论（吉）；忌入六外宫=失/破财（凶）
- ★人位忌入人位=管束；桃花星自化忌=桃花收束
- ★禄忌互换：我化禄给他、他化忌给我→单方面付出
- ★忌忌互换/互冲忌：互相伤害纠缠
- ★禄转禄→好上加好；禄转忌→得中有失；忌转禄→因祸得福；忌转忌→雪上加霜
- ★交会忌：多宫化忌聚某宫→该宫伤害最大
- ★长寿格：生年禄+生年科落在命/迁/父/疾→长寿架构

### 3.7 化忌特殊论（来源：《全书》卷二）

- ★化忌庙陷总则：诸星庙地化忌不忌（庙旺有力化解）；日月庙旺化忌反为福论（太阳寅卯辰巳午/太阴酉戌亥子）；日月陷地化忌=大凶；火性星（太阳火铃廉贞七杀）陷地化忌凶力倍增（来源：《全书》+《命理新编》）
- 天同在戌化忌丁生人遇吉反佳；巨门在辰化忌辛生人返佳
- 五行生克解忌：如廉贞在亥化忌、水命人化忌亦不为害（火入水乡受制）；水命化忌=难耐久

### 3.8 流年四化

- 流年四化看当年发生之事，以大限为体、流年为用
- 流年化忌入财帛→破财；入疾厄→有病；入官禄→事业受阻
- 流年化禄叠原命化禄→财运大旺；大限化忌冲流年化忌→双忌大凶

### 3.9 四化五行属性（来源：《全书》卷二）

- 化禄属土（喜见禄存）、化权属木（喜会巨门武曲）、化科属水（喜会魁钺）、化忌属水（即计都星）

## 第四章 先天命数分析

### 4.1 分析步骤
1. 看命宫主星庙旺定格局 → 2. 看三方四正综合判断 → 3. 看身宫补充 → 4. 看格局 → 5. 看六亲宫 → 6. 看四化落宫 → 7. 综合论断
- 骨髓赋另诀：「第一先看福德，再三细考迁移」（古典全书以福德迁移为重）
- 命宫无正曜者，财官有吉星拱照亦可富贵（或偏房庶母所生、二姓延生）

### 4.1a 观星四要（来源：《命理新编》第28章）
- ★要分清主宾：本方之星为主，对方合方邻方之星为宾（同1.2太微赋主宾原则）
- ★要辨别庙陷：星所主之事有善恶，善恶随其地有庙陷。庙为吉星陷为凶星，庙旺化吉陷落化凶
- ★要分清实虚：本方为实，对方为虚；甲级星为实，乙级以下为虚。本方甲级星先看，后看对方合方

## 第九章 钦天四化心学要点（来源：《字4》）

### 9.1 来因宫断法
- ★来因宫=生年天干五虎遁入地支相合之宫，为一切因缘来处
- 来因宫提供五个基本讯息：来缘位+生年四化ABCD
- 来缘三类：来缘在父母（先天格局）、来缘在自己（自立格局）、来缘在婚姻（他立格局）
  - 来因在父子友→来缘归父；来因在兄疾田→来缘归母
- 看盘从来因宫起→再看生年四化定位→自化加入变数→综合结论

### 9.2 自化理论
- 自化=本宫或对宫天干对星辰产生质能改变（直线作用力，大于飞宫的抛物线作用力）
- **离心力自化**（本宫自化）：生年四化「散」的作用→运限走到该宫时生年四化终止
- **向心力自化**（对宫化入）：生年四化「聚」的作用→运限走到该宫时生年四化启动
- 自化三种作用范围：①与生年四化的关系 ②与其他自化的关系 ③与宫位的关系
- ★自化是时空的用神：不同向性的自化在时空上含义不同
- 自化与生年同星→分「同组」（事到此止）与「不同组」（事要扩大）
- 串联=多个同向自化连接→因缘巧合（类聚）
- 禄忌主物（财），权科主情（人）

### 9.2b 钦天四化·四季象与星辰八卦（来源：《六玄经脉》蔡明宏）

- **命忌**（痴情忌，会强烈冲对宫）入：兄弟=重成就存款不喜应酬，冲交友；夫妻=在乎感情但争执控制，冲官禄年轻工作不稳；子女=在乎孩子酷爱投资搬家，冲田宅库；财帛=现实要挣钱，冲福德没享受；疾厄=活在自己感受里易焦虑抑郁，冲父母；迁移=总想外跑证明自己但耿直多挫折（天机廉贞巨门太阴忌防意外碰撞）；交友=信朋友到后来利益纠纷，冲兄弟必破财；官禄=一心工作不善恋爱，冲夫妻；田宅=全心顾家但家多争吵，冲子女；福德=为嗜好挥霍，冲财帛；父母=孝顺但顶嘴，冲疾厄身体差；★命自化忌=内敛自我纠结、易放弃中断自卑，冲迁移
- 生年忌（缘分注定）与命忌（性格执着）区别：命忌可自我调整（知命改命主要在命四化）
- ★命忌逢生年忌同宫=双倍以上辛苦，要什么什么不顺；（例外：命忌入迁移逢生年忌且迁移无他化=逆水忌）
- 忌逢生年禄：①遇缓冲（对方宽容）②禄忌成双（两份财路/多个桃花），谁得谁损分我宫他宫
- **命权**：入命福疾=自信强势；入六亲宫=支持该亲、想收回控制即争吵；入财官田迁=积极争取开创扩大
- **命科**：对该宫随意不强求、有情义、我是该宫贵人；★任何宫禄权科入命=该宫之人是我贵人
- 命宫禄因忌果：命禄入处=我喜欢/投入什么，命忌入处=为了什么/结果什么（如命禄入福德命忌入迁移=追求理想为谋社会一席之地）

### 12.10 自化
- ★自化=离心力：中断、拆台、节外生枝、放弃；任何自化代表该宫充满变数
- 自化禄=无中生有、心血来潮突然多出、三分热度不了了之；自化忌=不领情、通吃无回报、犹豫自卑中断
- 自化=该宫的外在表现（自化禄示人以禄、自化忌示人以固执排外，内里未必）
- ★自化禄法生年禄，自化忌法生年忌（自化的根源在生年四化之宫）
- 我宫禄入逢他宫自化忌=热脸贴冷屁股；他宫忌逢我宫自化禄=我宫被劫
- 生年禄自化忌=由好变坏由多变少；生年忌自化禄=由坏转好由少变多（皆禄忌交战）
- 命盘5处以上自化禄忌=难以朝九晚五踏实做事
- 自化科=有点拖拉、感情拖泥带水、过度斯文
- 两宫互为自化禄忌（如夫妻自化禄忌入财帛、财帛自化忌禄入夫妻）=一辈子扯不清无结果

### 12.11 特殊宫位（四化聚集之宫）
- ★一宫同时有生年四化（果报）+命四化（心力）+自化（变数），尤以禄忌叠加为重=命运重点与极端多变之处，看盘第一时间找出
- 夫妻宫、疾厄宫最好单纯：一颗主星（最好非杀破狼）、无生年四化、无命四化、无自化
- 特殊宫位重叠哪个大限宫，该大限即在该方面混乱

### 12.12 大限流年飞星法
- ★宫位重叠：以大限命重排十二宫，看本命生年四化、命四化、特殊宫位落入哪个大限宫=该十年应事；本命为体、大限为用；流年同理套入
- 流年命重叠大限命或本命命宫=力量加倍
- 来因宫进入大限命财官=生年四化对工作挣钱作用更明显
- 大限盘先找忌重叠的宫位较应验（人对忌之感受远大于禄）
- ★同类宫相应（同名宫：本命/大限/流年）：禄入=顺利有机会；忌入=黏着辛苦；禄照=明显好处；忌冲=中断破坏缘分不佳（最重要）
- ★用冲体（大限同类忌冲本命同类）=十年大部分时间不好，损失最重；体冲用（本命冲大限）较轻，仅个别流年
- 问什么找什么，飞星不满盘飞；先本命→大限→流年；本命应于大限、大限应于流年、流年应于流月
- ★流年走到大限某宫发出禄忌之落点、或被禄照忌冲之点，当年事发（不必用流年再飞）
- 大限命四化回本命：禄入=该十年对什么有兴趣/顺利；忌入=在乎什么、冲对宫缘薄；权入=要掌控改变什么；科入=对什么温和有恩情
- ★命三方不宜互冲：财帛忌入迁移冲命=财缘弱；官禄忌入迁移冲命=工作缘弱/运气差；官禄忌入福德冲财帛=努力无收入；财帛忌入夫妻冲官禄=工作中经济吃紧
- 大限不宜：大限命忌冲本命、大限财帛忌冲本命财帛、大限官禄忌冲本命官禄；大限三方互冲亦不好，投资谨慎
- ★反弓忌：大限命走本命财帛或官禄时化忌冲本命命财官=最严重，工作财路必损（内退、撤职、投资失败）
- ★父疾线=光明（文书公职前途）、兄友线=成就（人际现金流）：本命/大限官禄禄权科入此二线=有前途成就（公职宜入父疾线主晋升，生意宜入兄友线主盈利）；忌入=宜安稳勿折腾；大限财帛同理
- 大限盘本身各宫互飞亦可看细节（如大限命忌入大限夫妻=此限用心感情而不顺）

### 12.13 职业判断
- ①生年四化落官禄、财帛=易做该星之职业（禄忌更明显）；双星组合在内局更显著
- ②命四化：如命丙天同禄入官禄=医护餐饮；命甲廉贞禄入官禄=美术设计演艺；命戊贪狼禄入子女=教师；命乙天机或壬天梁禄入交友福德迁移子女=宗教命理
- ③★来因宫配生年四化（最准）：来因父母疾厄=公职国企学校银行代理服务；交友=服务业；子女=合伙投资小辈教育宠物；命官财=看官禄财帛禄忌之星；迁移=外出谋生；田宅=家族产业店面；福德夫妻不宜以来因断职业

### 12.14 婚姻断法
- 夫妻禄入命/福德/疾厄=得异性喜欢/兴趣相投/身体舒适；稳定婚姻=夫妻宫无生年忌、命忌、自化

## 第十四章 令东来论命要点（来源：《字令》令东来《紫微斗数命理学》第三版2019，中州派脉络，重星曜轻飞化）

### 14.1 总则
- ★先明格局，次看众星；只看宫干飞化不看星曜"十有六七不准"（宫干=想法，地支=环境）
- 某些格局带煞忌仍成格：巨门化忌午宫仍石中隐玉；太阴化忌亥宫仍月朗天门；七杀午宫同铃星不破格
- 男女断法不同（男重事业女重婚姻）；只有紫府日月可称"主星"，余称正曜；宫名用"奴仆宫"
- ★不可照搬书本铁口直断：同象可有多种应验（天机化忌冲官禄=多变动，或=为学业事业奔波）
- "两可之间"：某宫吉煞力量相近时，个人选择（如晚婚）可改结果；力量悬殊则"形势比人强"
- 庙陷：入庙不一定吉，失陷不一定凶；不可固执认为落陷化忌比入庙化忌更凶
- 命主、身主无用（附录四）

### 14.2 禄存与财星
- 财星三：武曲（现金）、太阴（计划之财）、天府（储藏）；禄星二：禄存、化禄
- ★禄存喜天马（禄马交驰）、化禄同宫/三方/六合（明禄暗禄）；忌空劫、化忌同宫（羊陀夹忌=败局，但财帛宫羊陀夹忌不一定坏）
- ★禄存/双禄落空亡不能为福：靠技术求财、财不稳
- 禄存入六亲宫=数量少；禄存坐命不宜同天机天梁（太孤）；禄存受同宫星支配
- 所有星喜三方会禄；同宫禄存或自化禄反多缺点（贪狼化禄坐命=重享受）

### 14.3 十四正曜要点
- 天府：能制羊陀、化火铃，★最畏空劫（地空=暗耗，地劫=明损）；守成强于创业，30岁后发力

- 天相喜成对吉星夹（左右/昌曲/魁钺），畏成对煞夹；★天相独坐宜辅佐，不宜一把手
- 紫微：百官朝拱/孤君在野/无道之君三类；★无左右即使有昌曲魁钺也孤，非大富贵
- 紫贪桃花犯主（卯重于酉），喜地空天刑制；紫破紫杀宜男不宜女
- 武曲：女命为寡宿；★贪武同行（丑未辰戌）+火铃同贪狼+禄=大发，30后发；见羊陀空劫忌=暴败
- ★铃昌陀武：辰戌最凶，武曲化忌+陀罗同宫最重；限年昌陀飞入亦成但较轻

- ★杀居绝地：七杀寅申/紫杀巳亥坐命而命宫逢长生"绝"=中年防意外（肺）
- 破军：化气为耗；对禄依赖比七杀更强；不宜昌曲尤畏昌曲化忌；寅申落陷六亲缘浅
- 太阳：★重昼夜生（寅至未时为昼，申至丑为夜，夜生乏力）；卯宫日照雷门优于午宫金灿光辉

- 太阴：主学与才（太阳主品与德）；庙旺喜昌曲化科，落陷反喜左右；★亥宫月朗天门，太阴化忌坐命不为凶

### 14.6 四化论（第十九章）
- ★四化是动态（正在变化），原局四化影响一生最大，大限主十年，流年主一年，三代四化共参
- ★四化表沿用《全书》：戊右弼科、壬左辅科；不采王亭之戊太阳科、庚壬天府科
- ★庚干：太阳禄、武曲权、太阴科、天同忌，**另加天相忌**（庚干双忌，作者称古本《全书》所传，见冲突#1、#6）
- 庚年天相化忌：宜副手，不宜从政，得外界助力小；破军坐命受对宫天相化忌冲
- 化禄=利益温和；化权=权力强势；化科=知名度（可能恶名）；化忌=不满不舒服
- 命宫四化：相貌随大限变化（禄→亲切，权→严肃，科→斯文，忌→纠结）
- ★光溜溜的化禄权科无吉星配合效果有限；禄权科非必吉，忌非必凶

- 流月四化一般影响不大；★流月四化按节气换月干，但流月宫位不因节气而变
