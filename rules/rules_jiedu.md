## 第一章 核心术语

- **正星14颗**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军
- **六吉星**：左辅、右弼、天魁、天钺、文昌、文曲；加禄存、天马为八吉
- **四煞**：擎羊、陀罗、火星、铃星；加天空、地劫为六煞
- **四化**：化禄（吉/财）、化权（权/竞争）、化科（名/贵人）、化忌（凶/损耗）
- **三方四正**：本宫+三合两宫+对冲宫，论命主线
- **朝/冲**：吉星居对宫=朝，凶/化忌在对宫=冲
- **辅/夹**：吉星分居两邻宫=辅，凶星夹=夹
- **庙旺得陷**：庙>旺>得>陷，庙旺充分发挥，陷落无力
- **四恶曜**：杀破廉贪，失陷遇煞大凶，入庙反具横发力
- **杀破狼**：永远三合会照，限年逢之主变革开创
- **天罗地网**：辰宫（天罗）、戌宫（地网），捆绑之象
- **本对合邻力量**（来源：《初级讲义》）：本宫60%、对宫40%、合宫（三合）20%、邻宫10%
- **《十喻歌》原则**：本方吉=由内自强；本方凶=从根自伐；对方吉=迎面春风；对方凶=当头恶棒；合方吉=左右逢源；合方凶=左右受敌；邻方吉=两邻相扶；邻方凶=两邻相侮
- **身宫落宫效果**：命身同宫=性格明显内外一致；身入夫妻=特别在意感情；身入财帛=重财不重名；身入迁移=喜出外易转工搬家；身入事业=事业心重；身入福德=重享受生活品味

## 第三章 四化象

### 3.1 四化基本含义

**化禄**：财禄/食禄/福禄、人缘佳/异性缘、忙碌/好施舍、聪明/才艺、增加增多、解厄延寿
**化权**：权势/威严、掌权/领导、任性/果决、能干/专技/开创、争执/外伤、增值
**化科**：科甲/功名、声名/念旧、聪明/博学/才艺、平顺/计划、贵人/解厄、风度/桃花
**化忌**：变动/驿马/不安、收藏/收束、亏欠/固执/情谊、不顺/困扰/是非、凶兆/灾厄、缘薄

### 3.3 四化入宫简断

- ★禄入六亲宫→与该亲缘厚、借其力显彰；入财官→忙碌得财/事业有成
- ★权入六亲宫→该亲能干掌权、与之争执；入财→敢赚敢花；入官→掌权开创
- ★科入六亲宫→该亲聪明有风度、与之和睦、该亲为贵人；入官→求学顺利
- ★忌入六亲宫→对该亲亏欠、缘薄；入命→不顺/钻牛角尖/不宜创业；入财→辛苦守财不牢

### 3.4 生年四化（体）vs 飞宫四化（用）vs 自化（造化）

- **生年四化**：先天定数，命的本质，决定富贵贫贱之格
- **飞宫四化**：宫干飞出四化入他宫，动态吉凶，宫象星合一
- **自化**：宫干四化落回本宫，后天变数，有中化无/无中生有
- **视同自化**：宫干四化落入对宫，意义近自化，另含不断缘起

### 3.5 自化叠化规则

| 组合 | 效果 |
|------|------|
| 禄+自化禄 | 同类抵消=无禄 |
| 禄+自化忌 | 禄忌=双忌论 |
| 权+自化权 | 同类抵消=无权 |
| 权+自化忌 | 权可解忌，想做又不做 |
| 科+自化科 | 同类抵消=无科 |
| 科+自化忌 | 科可解忌但不彻底 |
| 忌+自化禄 | 禄忌=双忌 |
| 忌+自化忌 | 同类抵消=不忌 |

### 3.6 四化飞伏关键规则

- ★化忌入宫=引坏，化忌冲宫=真正破坏；一颗化忌牵动三宫（坐忌、冲宫、冲宫的三合）
- ★忌入六内宫=收藏得财论（吉）；忌入六外宫=失/破财（凶）
- ★人位忌入人位=管束；桃花星自化忌=桃花收束
- ★禄忌互换：我化禄给他、他化忌给我→单方面付出
- ★忌忌互换/互冲忌：互相伤害纠缠
- ★禄转禄→好上加好；禄转忌→得中有失；忌转禄→因祸得福；忌转忌→雪上加霜
- ★交会忌：多宫化忌聚某宫→该宫伤害最大
- ★长寿格：生年禄+生年科落在命/迁/父/疾→长寿架构

### 3.7 流年四化

- 流年四化看当年发生之事，以大限为体、流年为用
- 流年化忌入财帛→破财；入疾厄→有病；入官禄→事业受阻
- 流年化禄叠原命化禄→财运大旺；大限化忌冲流年化忌→双忌大凶

## 第四章 先天命数分析

### 4.1 分析步骤
1. 看命宫主星庙旺定格局 → 2. 看三方四正综合判断 → 3. 看身宫补充 → 4. 看格局 → 5. 看六亲宫 → 6. 看四化落宫 → 7. 综合论断

### 4.2 格局要点
- **吉格**：主星庙旺+吉星扶助+无煞冲破
- **凶格**：主星陷落+四煞齐聚+化忌冲命
- ★杀破狼格：三方聚，入庙富贵，失陷漂泊
- ★机月同梁格：天机太阴天同天梁聚，宜公职
- ★紫府朝垣：紫微天府同宫或三方会，主大贵
- ★日月照壁：太阳太阴对照命宫，主名望

### 4.3 岁限分析
- 原命局管一生，大限管十年，流年管一年
- 命局吉+大限吉+流年吉=大吉；命凶+大限凶+流年凶=大凶
- 北斗星应前半段，南斗星应后半段（大限前5年/后5年，流年上/下半年）
- 大限化禄权科均吉，化忌主凶；重点跟踪化忌和化禄
- 叠禄=力量大增，叠忌=大凶；原局化禄逢限年化忌=由好变坏

## 第五章 星曜性情·疾病·职业

- ★子午卯酉受贪狼影响→主桃花，耳软心活，紫贪怕化忌科忌
- ★辰戌丑未受破军天相影响→重名禄，主掌权，紫破主孤高；紫相同度薄情无义
- ★寅申巳亥受天府七杀影响→主孤寂，具领导但脆弱；紫府同度魄力有余决断不足，宜公职不宜最高决策

- ★不会左右：多劳碌难成大业；会左右：量度大有成就
- ★四煞陷地冲命：多残疾或不善终
- 格局：紫微居午无刑忌→公卿；紫府朝垣活禄逢→福厚；君臣庆会→极贵
- 格局：桃花犯主→邪淫；极居卯酉→僧道；紫杀化权→反吉；紫破欺公→横发终败
