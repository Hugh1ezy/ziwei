## 第一章 核心术语

- **正星14颗**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军
- **六吉星**：左辅、右弼、天魁、天钺、文昌、文曲；加禄存、天马为八吉
- **四煞**：擎羊、陀罗、火星、铃星；加天空、地劫为六煞
- **四化**：化禄（吉/财）、化权（权/竞争）、化科（名/贵人）、化忌（凶/损耗）
- **三方四正**：本宫+三合两宫+对冲宫，论命主线
- **朝/冲**：吉星居对宫=朝，凶/化忌在对宫=冲
- **辅/夹**：吉星分居两邻宫=辅，凶星夹=夹
- **庙旺得陷**：庙>旺>得>陷，庙旺充分发挥，陷落无力
- **四恶曜**：杀破廉贪，失陷遇煞大凶，入庙反具横发力
- **杀破狼**：永远三合会照，限年逢之主变革开创
- **天罗地网**：辰宫（天罗）、戌宫（地网），捆绑之象；辰戌生人逢本宫岁限尤忌
- **本对合邻力量**（来源：《初级讲义》）：本宫60%、对宫40%、合宫（三合）20%、邻宫10%
- **《十喻歌》**：本方吉=自强，凶=自伐；对方吉=春风，凶=恶棒；合方吉=逢源，凶=受敌；邻方吉=相扶，凶=相侮
- **身宫落宫效果**：命身同宫=性格明显内外一致；身入夫妻=特别在意感情；身入财帛=重财不重名；身入迁移=喜出外易转工搬家；身入事业=事业心重；身入福德=重享受生活品味
- ★身宫从出生即起作用（非坊间所说30岁后才起作用），只是随年龄增大越来越明显（来源：《内部讲义》）
- 命宫=抓什么牌，身宫=怎么出牌；身宫所处宫气越弱人生越折腾
- **解盘三原则**（来源：《内部讲义》）：宫定环境、星定本质、干定来由（宫/星/干各占象三分之一）
- **八宫概念**：看任何宫位须同时看本宫三方四正+对宫三方四正共八宫；立极不忘起初，所有分析回归命宫

### 1.x 十二长生宫气（来源：《内部讲义》古法）

- ★五行局决定十二长生起始：金长生巳、木长生亥、火长生寅、水土长生申
- 方向与大限一致（阳男阴女顺，阴男阳女逆）
- 旺气序：长生→沐浴→冠带→临官→帝旺（渐旺）；衰→病→死→墓→绝（渐弱）；胎→养（有生机）
- ★弱气≠凶，旺气≠吉，是星运行的环境；弱气主浮动波动大多败少成，旺气主稳定
- 墓绝虽弱但离旺气最近有生机；帝旺过后"风雪将至"

### 1.2 太微赋纲领（来源：《全书》卷一）

- ★紫微天府全依辅弼之功，七杀破军专依羊铃之虐
- ★诸星吉逢凶也吉，诸星凶逢凶也凶
- ★主强宾弱可保无虞，主弱宾强凶危立见（主星vs客星力量原则）
- ★禄逢冲破吉处藏凶，马遇空亡终身奔走
- ★生逢败地发也虚花，绝处逢生花而不败
- ★日月守不如照合，荫福聚不怕凶危
- ★辅弼夹帝为上品，桃花犯主为至淫
- ★殺居絕地天年夭似顏回，贪坐生鄉壽考永如彭祖
- 片火焚天马，重羊逐禄存（火星克天马；擎羊克禄存）
- 前后两凶神为两邻，加会尚可撑持，同室与谋最难堤防（夹比同宫伤害大）

### 1.3 骨髓赋要诀（来源：《全书》卷一）

- ★命无正曜夭折孤贫（命宫无正星=大凶，须借对宫或财官吉星方可）
- ★七杀破军宜出外，机月同梁作吏人（古赋限定命在寅申方论）
- ★廉贞七杀反为积富之人（经典反格）
- ★先贫后富武贪同身命之宫（武贪同守先贫后富）
- 巨机同宫公卿之位，贪铃并守将相之名
- 铃昌罗武限至投河（铃+文昌+陀罗+武曲限年=大凶）
- 巨火擎羊终身缢死（巨门+火星+擎羊=缢死凶格）
- 天梁遇马女命贱而且淫
- 天机天梁擎羊会早有刑而晚见孤
- 贪狼武曲廉贞逢少受贫而后享福
- 夹贵夹禄夹权夹科=吉；夹空夹劫=贫贱，夹羊夹陀=乞丐
- 心好命微亦主寿，心毒命固亦夭亡

## 第二章 十二宫含义

| 宫位 | 核心含义 |
|------|---------|
| 命宫 | 个性、才华、格局高低、运势起伏、相貌 |
| 兄弟 | 兄弟缘分厚薄；私人机构、直销传销 |
| 夫妻 | 配偶个性才华家世、婚姻观、姻缘类型；隐含性=财帛宫的夫妻位 |
| 子女 | 子女格局、合伙位、桃花宫、性生活、娱乐休闲、意外宫 |
| 财帛 | 理财能力、赚钱机会、财的来龙去脉 |
| 疾厄 | 健康体质、疾病灾厄；意识形态、脾气、心术正邪 |
| 迁移 | 外出变迁运、人生机遇、贵人运、老运走势 |
| 奴仆 | 交友缘分、部属助力；众生相、绝情宫、寿元关键宫 |
| 官禄 | 运势起伏（气数宫）、事业状态、学业考运、功名官运 |
| 田宅 | 祖业不动产、住宅环境、家运、库位 |
| 福德 | 福气道德、享福应酬、身心健康、因果位、造化宫 |

> 福德弱气特征（《内部讲义》）：前三限冲动任性博而不专（疾宫旺在撑），三限后前期挥霍显现；化解：通风向阳、多外出走动、阴以阳解
| 父母 | 父母格局、长上缘分；文书宫、相貌宫、头脑智商 |

### 2.2 本对宫强弱互补（来源：《内部讲义》）
- ★本宫与对宫必定一强一弱（以十二长生宫气定），十二宫皆如此
- 命弱迁旺=适合外出发展；命旺迁弱=外出后受命宫旺气正面辅助
- 财旺福弱=来财机会多但抓不住；福旺财弱=机会少但能把握
- 夫旺官弱/官旺夫弱=事业与婚姻很难同时美满
- 子旺田弱=注意怀孕期/流产/家宅不安；田旺子弱=注意子女教育
- 疾旺父弱=承载力强但父辈弱/遗传病可能；父旺疾弱=长辈荫庇但自身承载差

### 2.3 六合宫融合（来源：《内部讲义》古法）
- ★地支六合（子丑、寅亥、卯戌、辰酉、巳申、午未）导致对应宫位力量融合
- 六合宫弱气方为主导（弱气方为问题根源）
- 疾福六合=先天耗神，精神与身体互相拖累；戊癸入=因情耗神，甲廉贞入=因事业耗神
- 夫父六合=婚姻感情受父母影响（父弱=阻力压力）
- 兄夫六合弱气见桃花=闺蜜/朋友抢配偶
- 疾官/疾夫六合=创业比例最高的组合
- 命田六合=根基与田宅融合，一动皆动，四海为家
- 子福六合精神宫弱=想要孩子又怕生孩子，教育不稳定

### 2.4 宫位特殊论断（来源：《全书》）
- ★父母宫日月论：太阳陷宫先克父，太阴陷宫先克母；二星俱陷日生主父存、夜生主母在
- ★子女宫生男生女：三方四正南斗多主生男，北斗多主生女；太阳阳宫先生男，太阴阴宫先生女
- 男命强宫：财帛、官禄、福德、迁移、田宅；弱宫：子女、奴仆、兄弟、父母
- 女命强宫：夫君、子息、财帛、田宅、福德

## 第三章 四化象

### 3.1 四化基本含义

**化禄**：财禄/食禄/福禄、人缘佳/异性缘、忙碌/好施舍、聪明/才艺、增加增多、解厄延寿；★恶曜来临并羊陀火忌冲照亦不为害（化禄解凶能力强）
**化权**：权势/威严、掌权/领导、任性/果决、能干/专技/开创、争执/外伤、增值；逢羊陀耗使劫空=官灾贬谪
**化科**：科甲/功名、声名/念旧、聪明/博学/才艺、平顺/计划、贵人/解厄、风度/桃花；★虽四杀冲破亦为富贵
**化忌**：变动/驿马/不安、收藏/收束、亏欠/固执/情谊、不顺/困扰/是非、凶兆/灾厄、缘薄

### 3.3 四化入宫简断

- ★禄入六亲宫→与该亲缘厚、借其力显彰；入财官→忙碌得财/事业有成
- ★权入六亲宫→该亲能干掌权、与之争执；入财→敢赚敢花；入官→掌权开创
- ★科入六亲宫→该亲聪明有风度、与之和睦、该亲为贵人；入官→求学顺利
- ★忌入六亲宫→对该亲亏欠、缘薄；入命→不顺/钻牛角尖/不宜创业；入财→辛苦守财不牢

### 3.4 生年四化（体）vs 飞宫四化（用）vs 自化（造化）

- **生年四化**：先天定数，命的本质，决定富贵贫贱之格
- **飞宫四化**：宫干飞出四化入他宫，动态吉凶，宫象星合一
- **自化**：宫干四化落回本宫，后天变数，有中化无/无中生有
- **视同自化**：宫干四化落入对宫，意义近自化，另含不断缘起

### 3.5 自化叠化规则

| 组合 | 效果 |
|------|------|
| 禄+自化禄 | 同类抵消=无禄 |
| 禄+自化忌 | 禄忌=双忌论 |
| 权+自化权 | 同类抵消=无权 |
| 权+自化忌 | 权可解忌，想做又不做 |
| 科+自化科 | 同类抵消=无科 |
| 科+自化忌 | 科可解忌但不彻底 |
| 忌+自化禄 | 禄忌=双忌 |
| 忌+自化忌 | 同类抵消=不忌 |

### 3.6 四化飞伏关键规则

- ★化忌入宫=引坏，化忌冲宫=真正破坏；一颗化忌牵动三宫（坐忌、冲宫、冲宫的三合）
- ★忌入六内宫=收藏得财论（吉）；忌入六外宫=失/破财（凶）
- ★人位忌入人位=管束；桃花星自化忌=桃花收束
- ★禄忌互换：我化禄给他、他化忌给我→单方面付出
- ★忌忌互换/互冲忌：互相伤害纠缠
- ★禄转禄→好上加好；禄转忌→得中有失；忌转禄→因祸得福；忌转忌→雪上加霜
- ★交会忌：多宫化忌聚某宫→该宫伤害最大
- ★长寿格：生年禄+生年科落在命/迁/父/疾→长寿架构

### 3.7 化忌特殊论（来源：《全书》卷二）

- ★太阳在寅卯辰巳午化忌、太阴在酉戌亥子化忌=庙旺化忌反为福论；日月陷地化忌=大凶
- 天同在戌化忌丁生人遇吉反佳；巨门在辰化忌辛生人返佳
- 五行生克解忌：如廉贞在亥化忌、水命人化忌亦不为害（火入水乡受制）

### 3.8 流年四化

- 流年四化看当年发生之事，以大限为体、流年为用
- 流年化忌入财帛→破财；入疾厄→有病；入官禄→事业受阻
- 流年化禄叠原命化禄→财运大旺；大限化忌冲流年化忌→双忌大凶

### 3.9 四化五行属性（来源：《全书》卷二）

- 化禄属土（喜见禄存）、化权属木（喜会巨门武曲）、化科属水（喜会魁钺）、化忌属水（即计都星）

## 第四章 先天命数分析

### 4.1 分析步骤
1. 看命宫主星庙旺定格局 → 2. 看三方四正综合判断 → 3. 看身宫补充 → 4. 看格局 → 5. 看六亲宫 → 6. 看四化落宫 → 7. 综合论断
- 骨髓赋另诀：「第一先看福德，再三细考迁移」（古典全书以福德迁移为重）
- 命宫无正曜者，财官有吉星拱照亦可富贵（或偏房庶母所生、二姓延生）

### 4.1b 看命条件判断（来源：《字全2》南北山人经验谈）
- 命身佳美但财官迁三宫有一煞冲=秀而不实
- 财宫优于官宫=以富断；官宫优于财宫=以贵断
- 命身吉+官禄佳但财宫欠美=公私俸禄无衣食之虑
- 财宫佳但官禄欠美=庶人/商贾/技艺
- 三宫皆欠吉=纵命身佳亦难青云

### 4.2 格局要点
- **吉格**：主星庙旺+吉星扶助+无煞冲破
- **凶格**：主星陷落+四煞齐聚+化忌冲命
- ★杀破狼格：三方聚，入庙富贵，失陷漂泊
- ★机月同梁格：天机太阴天同天梁聚，宜公职（古赋限定命在寅申方论，加吉则不以此论）
- ★紫府朝垣：紫微天府同宫或三方会，主大贵
- ★日月照壁：太阳太阴对照命宫，主名望

### 4.2b 格局九等（来源：《全书》卷三）
- 星上格+数上格=第一（极品之贵），星上+数中=第二（三公），星上+数下=第三（六卿）
- 星中+数上=第四（监司），星中+数中=第五（县令），星中+数下=第六（异路前程）
- 星下+数上=第七（衣禄丰足），星下+数中=第八（衣食无亏），星下+数下=第九（贫穷夭折）

### 4.3 岁限分析
- 原命局管一生，大限管十年，流年管一年
- 命局吉+大限吉+流年吉=大吉；命凶+大限凶+流年凶=大凶
- 北斗星应前半段，南斗星应后半段（大限前5年/后5年，流年上/下半年）
- ★阳男阴女南斗为福，阴男阳女北斗为福
- 大限化禄权科均吉，化忌主凶；重点跟踪化忌和化禄
- 叠禄=力量大增，叠忌=大凶；原局化禄逢限年化忌=由好变坏

### 4.3b 限运凶格（来源：《全书》卷三）
- ★羊陀迭并：原局擎羊冲命，流年又逢流羊流陀叠加=大凶；紫微天相禄存三合拱照可解

## 第九章 钦天四化心学要点（来源：《字4》）

### 9.1 来因宫断法
- ★来因宫=生年天干五虎遁入地支相合之宫，为一切因缘来处
- 来因宫提供五个基本讯息：来缘位+生年四化ABCD
- 来缘三类：来缘在父母（先天格局）、来缘在自己（自立格局）、来缘在婚姻（他立格局）
  - 来因在父子友→来缘归父；来因在兄疾田→来缘归母
- 看盘从来因宫起→再看生年四化定位→自化加入变数→综合结论

### 9.2 自化理论
- 自化=本宫或对宫天干对星辰产生质能改变（直线作用力，大于飞宫的抛物线作用力）
- **离心力自化**（本宫自化）：生年四化「散」的作用→运限走到该宫时生年四化终止
- **向心力自化**（对宫化入）：生年四化「聚」的作用→运限走到该宫时生年四化启动
- 自化三种作用范围：①与生年四化的关系 ②与其他自化的关系 ③与宫位的关系
- ★自化是时空的用神：不同向性的自化在时空上含义不同
- 自化与生年同星→分「同组」（事到此止）与「不同组」（事要扩大）
- 串联=多个同向自化连接→因缘巧合（类聚）
- 禄忌主物（财），权科主情（人）

### 9.3 十干化曜哲学观（来源：《字4》）
- 河图四化正位：四九金=化禄（子女/官禄→事业发展）、二七火=化权（兄弟/迁移/父母→变动转换）、三八木=化科（夫妻/交友→情寿进修）、一六水=化忌（命/疾/福→收藏实得）
- ★化忌在命疾福田=实得（吉论）；化忌在人位=对待问题
- 飞宫≠乱飞：不是每个宫位都可以飞，要有飞的原因和依据

### 9.4 心学星辰观
- ★紫微不是星（不具五行质象），代表天地合一的人位/中心
- 日月十星代表阴阳五行→象征五行，非代表五行（不可以星克星）
- 左右昌曲代表天与地人的链结→取自月时数，不依紫微布列
- 15星=河图中心数（10+12公倍数=60=花甲）
- ★空宫另论：紫微的第几位决定该宫性质（如紫微的田宅=巨门，以巨门论空宫）
