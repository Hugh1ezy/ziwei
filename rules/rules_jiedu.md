## 第一章 核心术语

- **正星14颗**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军
- **六吉星**：左辅、右弼、天魁、天钺、文昌、文曲；加禄存、天马为八吉
- **四煞**：擎羊、陀罗、火星、铃星；加天空、地劫为六煞
- **四化**：化禄（吉/财）、化权（权/竞争）、化科（名/贵人）、化忌（凶/损耗）
- **三方四正**：本宫+三合两宫+对冲宫，论命主线
- **朝/冲**：吉星居对宫=朝，凶/化忌在对宫=冲
- **辅/夹**：吉星分居两邻宫=辅，凶星夹=夹
- **庙旺得陷**：庙>旺>得>陷，庙旺充分发挥，陷落无力
- **四恶曜**：杀破廉贪，失陷遇煞大凶，入庙反具横发力
- **杀破狼**：永远三合会照，限年逢之主变革开创
- **天罗地网**：辰宫（天罗）、戌宫（地网），捆绑之象

## 第三章 四化象

### 3.1 四化基本含义

**化禄**：财禄/食禄/福禄、人缘佳/异性缘、忙碌/好施舍、聪明/才艺、增加增多、解厄延寿
**化权**：权势/威严、掌权/领导、任性/果决、能干/专技/开创、争执/外伤、增值
**化科**：科甲/功名、声名/念旧、聪明/博学/才艺、平顺/计划、贵人/解厄、风度/桃花
**化忌**：变动/驿马/不安、收藏/收束、亏欠/固执/情谊、不顺/困扰/是非、凶兆/灾厄、缘薄

### 3.2 四化入宫简断

- ★禄入六亲宫→与该亲缘厚、借其力显彰；入财官→忙碌得财/事业有成
- ★权入六亲宫→该亲能干掌权、与之争执；入财→敢赚敢花；入官→掌权开创
- ★科入六亲宫→该亲聪明有风度、与之和睦、该亲为贵人；入官→求学顺利
- ★忌入六亲宫→对该亲亏欠、缘薄；入命→不顺/钻牛角尖/不宜创业；入财→辛苦守财不牢

### 3.3 生年四化（体）vs 飞宫四化（用）vs 自化（造化）

- **生年四化**：先天定数，命的本质，决定富贵贫贱之格
- **飞宫四化**：宫干飞出四化入他宫，动态吉凶，宫象星合一
- **自化**：宫干四化落回本宫，后天变数，有中化无/无中生有
- **视同自化**：宫干四化落入对宫，意义近自化，另含不断缘起

### 3.4 自化叠化规则

| 组合 | 效果 |
|------|------|
| 禄+自化禄 | 同类抵消=无禄 |
| 禄+自化忌 | 禄忌=双忌论 |
| 权+自化权 | 同类抵消=无权 |
| 权+自化忌 | 权可解忌，想做又不做 |
| 科+自化科 | 同类抵消=无科 |
| 科+自化忌 | 科可解忌但不彻底 |
| 忌+自化禄 | 禄忌=双忌 |
| 忌+自化忌 | 同类抵消=不忌 |

### 3.5 四化飞伏关键规则

- ★化忌入宫=引坏，化忌冲宫=真正破坏；一颗化忌牵动三宫（坐忌、冲宫、冲宫的三合）
- ★忌入六内宫=收藏得财论（吉）；忌入六外宫=失/破财（凶）
- ★人位忌入人位=管束；桃花星自化忌=桃花收束
- ★禄忌互换：我化禄给他、他化忌给我→单方面付出
- ★忌忌互换/互冲忌：互相伤害纠缠
- ★禄转禄→好上加好；禄转忌→得中有失；忌转禄→因祸得福；忌转忌→雪上加霜
- ★交会忌：多宫化忌聚某宫→该宫伤害最大
- ★长寿格：生年禄+生年科落在命/迁/父/疾→长寿架构

### 3.6 流年四化

- 流年四化看当年发生之事，以大限为体、流年为用
- 流年化忌入财帛→破财；入疾厄→有病；入官禄→事业受阻
- 流年化禄叠原命化禄→财运大旺；大限化忌冲流年化忌→双忌大凶

## 第四章 先天命数分析

### 4.1 分析步骤
1. 看命宫主星庙旺定格局 → 2. 看三方四正综合判断 → 3. 看身宫补充 → 4. 看格局 → 5. 看六亲宫 → 6. 看四化落宫 → 7. 综合论断

### 4.2 格局要点
- **吉格**：主星庙旺+吉星扶助+无煞冲破
- **凶格**：主星陷落+四煞齐聚+化忌冲命
- ★杀破狼格：三方聚，入庙富贵，失陷漂泊
- ★机月同梁格：天机太阴天同天梁聚，宜公职
- ★紫府朝垣：紫微天府同宫或三方会，主大贵
- ★日月照壁：太阳太阴对照命宫，主名望

### 4.3 岁限分析
- 原命局管一生，大限管十年，流年管一年
- 命局吉+大限吉+流年吉=大吉；命凶+大限凶+流年凶=大凶
- 北斗星应前半段，南斗星应后半段（大限前5年/后5年，流年上/下半年）
- 大限化禄权科均吉，化忌主凶；重点跟踪化忌和化禄
- 叠禄=力量大增，叠忌=大凶；原局化禄逢限年化忌=由好变坏

## 第五章 星曜性情·疾病·职业

### 紫微星（己土·北斗帝王·官禄主）
- 化气曰尊，司爵禄，贵星/财星/寿星，主孤傲
- 【疾】脾胃之疾，湿热膨胀，腹泻呕吐
- ★子午卯酉受贪狼影响→主桃花，耳软心活，紫贪怕化忌科忌
- ★辰戌丑未受破军天相影响→重名禄，主掌权，紫破主孤高
- ★寅申巳亥受天府七杀影响→主孤寂，具领导但脆弱
- ★不会左右：多劳碌难成大业；会左右：量度大有成就
- ★四煞陷地冲命：多残疾或不善终
- 格局：紫微居午无刑忌→公卿；紫府朝垣活禄逢→福厚；君臣庆会→极贵
- 格局：桃花犯主→邪淫；极居卯酉→僧道；紫杀化权→反吉；紫破欺公→横发终败

### 天机星（乙木·南斗·兄弟主）
- 益寿保生，化气曰善，主智巧灵活，与宗教教育有关
- 【疾】肝胆之疾，四肢筋骨神经系统
- ★子午卯酉受巨门影响→主学术辩论，易口舌是非
- ★辰戌丑未受天梁影响→主宗教参谋，点子多，孝悌六亲
- ★寅申巳亥受太阴影响→主驿马感情，感情多波动

### 太阳星（丙火·中天·官禄主）
- 权贵之星，主父夫子，感情之星
- 【疾】脑疾眼疾，高血压头晕脑瘤近视
- ★子午卯酉受天梁影响→主健康公益学术
- ★辰戌丑未受太阴影响→主驿马感情，日月反背格（戌日辰月）不利
- ★寅申巳亥受巨门影响→主奔波争执

### 武曲星（辛金·北斗将星·财帛主）
- 寡宿之星，主有财（劳心劳力正财），精神孤虚
- 【疾】肺经呼吸系统，肺结核咳嗽
- ★子午卯酉受七杀天府影响→主肃杀，双将入命
- ★辰戌丑未受贪狼影响→主横发，武贪不发少年人，走己运横发
- ★寅申巳亥受天相破军影响→主驿马奔波动中求财

### 天同星（壬水·南斗·福德主）
- 益寿保生，温和谦逊，博学多闻，宜女不宜男
- 【疾】肝胆膀胱泌尿，疝气糖尿病
- ★子午卯酉受太阴影响→主桃花技艺；子宫=文贵清高，午宫=武贵（马头带箭格）
- ★辰戌丑未受巨门影响→主劳碌是非，先苦后福
- ★寅申巳亥受天梁影响→主驿马公关健康桃花

### 廉贞星（丁火·北斗·官禄主·囚星）
- 公权力之星，次桃花主，善恶兼具近朱近墨
- 【疾】化忌主疑难杂症（癌症肿瘤艾滋）
- ★子午卯酉受天相破军影响→主桃花是非官非牢狱
- ★辰戌丑未受七杀天府影响→动中求财辛劳，丑未=路旁埋尸格
- ★寅申巳亥受贪狼影响→主驿马桃花，亥宫=绝处逢生格

### 天府星（戊土·南斗帝王·财库星）
- 权令之星，主丰隆，相当于化科星，解厄延寿
- 【疾】脾胃之疾

### 太阴星（癸水·中天·田宅主·财帛主）
- 主母妻女，快乐主义，宜女不宜男
- 【疾】血液循环（糖尿高血压），血光之星

### 贪狼星（甲木·北斗·桃花主·财星·寿星）
- 主祸福，才艺之星
- 【疾】肝胆，风湿性病，男肾亏女赤白带

### 巨门星（癸水·北斗·口舌之神·是非之星）
- 性不明，遗弃之星，猜忌心，六亲寡合
- 【疾】胃寒胃病，哮喘喉炎

### 天相星（壬水·南斗·衣食之星·印星·官禄主）
- 主聪明好善，调解能力，专解廉贞之恶
- 【疾】膀胱糖尿皮肤

### 天梁星（戊土·南斗·父母星·荫星·寿星）
- 中康之星（医药），桃花星（交际公关），敏锐观察力
- 【疾】脾胃打嗝，脑颈相关

### 七杀星（庚金·南斗·大杀神·将星）
- 司斗柄掌生死，血光之星，性刚果决
- 【疾】与羊陀同宫恐残疾

### 破军星（癸水·北斗·性难明·主破耗）
- 孤剋之星，进退反复，有破必能修，学外语细胞强
- 【疾】肾水相关（阴亏阳痿遗精）

### 辅助星简述
- **左辅**（戊土）：行善令，灵巧慷慨（有偿），幼年不顺/庶出
- **右弼**（癸水）：行制令，好施舍（无偿），婚姻缺憾力强于左辅
- **文昌文曲**：功名星/桃花星；【疾】神经精神系统，与任何星同宫=并发症
- **天魁天钺**：天乙贵人，清白之神，科甲之星
- **天刑**：刚直，偏好命理法律医术佛学；不宜入六亲宫；主是非官非
- **天姚**：感情早熟，风雅幽默，异性缘浓；入夫妻=多艳遇
- **天马**：驿马，出国远行；禄马交驰=发财
- **禄存**：化气曰富，财王，天赋之财，解厄延寿；与巨门同宫可制化其恶
- **擎羊**：刚强粗暴，刑伤血光；【疾】肺经口歪羊癫疯
- **陀罗**：【疾】牙齿骨骼，骨折脱臼

## 第六章 活用预测

- 紫微占卜原则：不动不占，不问不占；意向越迫切越准确
- 起盘：按问事时间排盘（不排大小限），以用神宫为新命宫重布十二宫
- 用神取法：按问事内容对应宫位（问儿女→子女宫，问父母→父母宫）
- 论断：星情法+四化法，日干化忌落宫可测来人来意
- 看时运重视小星，主星仅作救应
