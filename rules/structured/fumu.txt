# 原文栏写"＝"表示结论就是原文，只按句拆开、未改字（错字照改并在原文栏注明）。编号前缀 A。
# 本表的"本宫"＝父母宫：同宫＝父母宫本宫；会＝父母宫的三方四正（父母、疾厄、奴仆、子女）；夹＝父母宫两邻宫；对宫＝疾厄宫；支＝父母宫地支。
#   星=X：父母宫主星有X（每条规则的前提）。父母宫无主星时，照旧借对宫主星（程序原有做法），此时同宫、支按对宫算。
#   【新增主题】父母（父母本身、与父母的缘份、刑克、福荫、上司），已加到 composer.js 的 TOPIC_ORDER、TOPIC_RE。

# 写法沿用福德、官禄、田宅及以前各表：
#   "加吉""见吉""吉众"写成"吉"；"加煞""见煞""凶煞""恶煞"写成"煞"；"四煞"写成"煞"，"四煞会齐"写成"会全:擎羊/陀罗/火星/铃星"；"六煞"写成"会:六煞"；
#   "煞忌"写成"煞＆化忌"；"煞刑忌""刑煞忌"写成"煞＆会:天刑＆化忌"；"煞刑忌混杂""煞刑忌聚"再加"煞多"；"化吉"写成"会化:禄/权/科"；
#   "桃花星"按"桃花"组；"空劫"写成"会:地空/地劫"；"左右昌曲双星""魁钺双星"写成 对:左右／对:昌曲／对:魁钺（成对会照）；"左右单星"写成 会:左辅＆不会:右弼 或 会:右弼＆不会:左辅。
#   "庙旺""失陷"按程序庙旺表；书自列地支的写成"支="（太阳"寅卯辰巳午宫为庙旺""申酉戌亥子丑失陷"照书写支=）；巨门陷地按书写成 支=辰/戌；天梁"平闲"按程序表非庙旺非陷写成 支=。
#   "化禄""化忌"等写在某星段内、未说是谁化的，指该星本身化；"逢化忌"未说谁化的按三方四正见化忌。
#   凶星连写不带"等"字的各类都要见到，成对之星见其一即算；带"等"字的见其一即算；吉星连写见其一即算。
#   "刑囚夹"读作 夹:擎羊＆夹:廉贞（擎羊为刑、廉贞为囚）；"忌夹"读作 夹化:忌；"羊陀夹"写成 夹全:擎羊/陀罗。
#   "火羊同守"写成 同宫:火星＆同宫:擎羊；"X同宫""X同度"写成 同宫:X。
# 未录：大限、流年、"逢流年化忌冲""逢廉贞化忌之年应灾""遇丧门白虎时父灾"等限运内容；"否则……"一类反面推论；
