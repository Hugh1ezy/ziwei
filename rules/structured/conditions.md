# 条件词表（试点：紫微在命宫）

规则表 `ziwei_minggong.txt` 的"条件"一栏只用下面这些写法。每个写法都是命盘上能直接读出来的一件事，
程序（`composer.js`）逐条判断。几个写法用"＆"连起来，表示必须同时成立。

隐含前提：命宫主星有紫微。

## 一、基本条件

| 写法 | 意思 | 例 |
|---|---|---|
| `支=子/午` | 命宫地支是其中之一 | 紫微在子或午 |
| `干=甲/丁/己` | 生年天干是其中之一 | 甲丁己年生 |
| `支年=亥/卯/未` | 生年地支是其中之一 | 亥卯未年生 |
| `性别=女` | 男命或女命 | |
| `局=2` | 五行局（2水 3木 4金 5土 6火） | |
| `长生=死/绝` | 命宫的长生十二神 | 命宫逢绝 |
| `入庙` | 紫微在午、丑、未（全书卷二："午宫入庙""丑未宫入庙"） | |
| `身宫有:破军` | 身宫里有这颗星 | |

## 二、见星的范围

| 写法 | 范围 |
|---|---|
| `同宫:X/Y` | 命宫本宫有X或Y |
| `会:X/Y` | 三方四正（本宫、对宫、两个三合宫）有X或Y（任一即可） |
| `不会:X/Y` | 三方四正一颗都没有 |
| `夹:X` | 左右两个邻宫有X |
| `对:左右` | 一对星两颗都在三方四正或邻宫（精成："守照会拱或在左右邻宫相夹"） |
| `夹对:左右` | 一对星分居两个邻宫，正好夹命 |

对星：府相（天府天相）、左右（左辅右弼）、昌曲（文昌文曲）、魁钺（天魁天钺）、日月（太阳太阴）、禄马（禄存天马）。

## 三、合成条件（书里定义好的说法，拆成上面的基本条件）

| 写法 | 拆开后 | 出处 |
|---|---|---|
| `百官` | 六组对星中至少一组满足"对" | 精成："至少得上述诸对星中的一对在三方四正守照会拱或在左右邻宫相夹者即为得'百官朝拱'" |
| `非百官` | 六组对星一组都不满足 | 精成：同上，"无上述诸对星或仅得其中之一单星……则为'孤君'" |
| `吉` / `无吉` | 三方四正有／没有 左辅、右弼、文昌、文曲、天魁、天钺 任一 | 字全书："吉星，代表左辅、右弼、天魁、天铖、文昌、文曲" |
| `煞` / `无煞` | 三方四正有／没有 擎羊、陀罗、火星、铃星 任一 | 字全书："凶徒，代表擎羊、陀罗、火星、铃星" |
| `四煞并见` | 三方四正有羊陀之一，又有火铃之一 | 精成："本宫同时见羊陀之一并火铃之一者就算数" |
| `三奇` | 生年化禄、化权、化科三颗星都在三方四正 | 全书卷三："科权禄三方照是也" |
| `禄马交驰` | 禄存、天马都在本宫或对宫 | 字陆·评注："禄存天马同度本宫，或是同度于对宫，或是一居本宫一居对宫" |
| `化:紫微=权` | 生年四化 | |
| `无化忌` | 三方四正没有生年化忌星 | 全书卷三"无刑忌"的"忌" |
| `会:桃花` | 红鸾、天喜、天姚、咸池、沐浴任一 | 精成："红、喜、贪、姚、咸、沐浴等桃花星"（贪狼是紫贪本身，不另算） |

## 五、复杂条件的拆分示例

- 全书卷二"若与府相左右日月昌曲三合嘉会"（按用户定：见一对即算）→ `百官`
- 全书卷二"不入庙无左右为孤君" → `不会:左辅/右弼＆支=子/寅/申/卯/酉/辰/戌/巳/亥`
- 南北派"紫微在陷地，又逢羊陀火铃冲，且不遇左右昌曲魁钺" → `不会:左辅/右弼/文昌/文曲/天魁/天钺＆会:擎羊/陀罗/火星/铃星`
- 精成"紫相辰戌守命而破军守身宫，无吉有煞" → `支=辰/戌＆身宫有:破军＆无吉＆煞`
- 精成"无百官再与四煞守照会夹……四煞并见为暴君" → `非百官＆四煞并见`

## 六、同一个词、各书条件不同（不能合并，分别保留）

**"孤君"三种定义**
1. 精成：六组对星一组都没有（`非百官`）
2. 全书卷二：不入庙且无左右；字全2、南北派、听课笔记、令东来：无左右（令东来："无左右即使有昌曲魁钺也孤"）
3. 字陆·讲义原文：没有左右昌曲魁钺，同时不入庙

所以一张盘可能按精成算"百官朝拱"、按全书算"孤君"。这是标准宽严不同，程序并列两说并加提示。

**同一结论，各书附加条件不同**（程序只在条件满足的那本书上计入来源）
- 紫微在子"丁己庚年贵格"：全书、字全2、南北派无附加条件；精成要"加吉"。
- 紫微在午"甲丁己位至公卿"：字全2无附加；南北派要"不会羊陀"；精成要"有左右吉众"；全书卷三要"无刑忌"。
- 丑未紫破的年干：全书"乙己甲庚丁壬"；字全2"甲乙丙丁戊己庚壬"；南北派"甲乙丙丁戊己壬"；精成"甲乙丁己庚，有吉扶"。

## 七、用户定的门槛（2026-10-22）

书上没有给数目，以下由用户决定：

| 写法 | 定义 |
|---|---|
| `吉多` | 三方四正内六吉与化禄、化权、化科合计 4 颗以上 |
| `煞多` | 三方四正内擎羊、陀罗、火星、铃星、地空、地劫合计 3 颗以上 |
| `煞少` | 同上合计 1–2 颗 |
| `君臣庆会` | 左右、昌曲、魁钺三组各见至少一颗 |
| "府相左右日月昌曲三合嘉会" | 不必全见，按精成"百官朝拱"（见到成对的一组即算） |
| 六吉 | 只算左辅右弼文昌文曲天魁天钺，不含禄存和化禄权科 |

"孤君"两种定义：用户指出不是矛盾，而是标准宽严不同。精成宽（任一对即不孤），全书严（以左右为核心，无左右即孤）。输出两说并列。
