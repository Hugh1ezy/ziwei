# 本表所有规则的隐含前提：命宫主星有紫微。条件写法见 conditions.md。
#
# 【甲部分定案，用户 2026-11-03】①"无破"＝无四煞＆无化忌＆无空亡（精成"不逢空亡煞忌冲破"、《紫微斗数集成全书》"不逢煞忌空亡"）；
#   ②"刑忌夹"按精成四说并列：擎羊化忌夹、羊陀夹（精成刑忌夹印格"古人称擎羊为刑，陀罗为忌"）、化忌天梁夹（府相朝垣格）、天刑化忌夹（官禄天府段），编号后缀 y/l/t；
#   ③"府库空露"按精成天府章：空库＝无禄而逢空劫截空旬空（后缀 k），露库＝有禄逢空劫或逢四煞（后缀 s）；财帛宫天府段自有"逢空星为空库……逢煞为露库"，照该段；
#   ④"空亡"按精成七杀段＝地空地劫截空旬空（精成空亡节另说只列天空截空旬空，不含地劫）；精成的"天空"即程序的"地空"，程序按年支安的"天空"是另一颗星，不并入；
#   ⑤生年只一化忌，"两个化忌并见"须生年忌加限运忌，限运未录，暂不触发。
# 【限运待录】Z062 南北派“大小限逢无吉星来会主破财”属行限条件（限会:无吉），已从本命行移出；本表暂无限运节，校验脚本也不认“限”行，先登记于此。
# 【解释性读法】Z343 陆讲义原文只说“女命有天府及吉辅星会照”，条件 支=寅/申 按同书评注“紫微天府是同度见吉曜，封诰夫人之命”读出。Z437 条件 性别=女＆支=辰/戌 按同书评注“紫微天相同度，破军对拱”读出。
# 【结构不可能】紫府夹命格（全书卷三“紫府夾命為貴格”）：紫微、天府相夹的命宫无正星（精成注“仅限寅申宫”“因无正星”），本表紫微坐命不可能成立，原 Z118 已移出，归空宫命/借星表。
