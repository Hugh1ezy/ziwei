# 本表所有规则的隐含前提：命宫主星有天府。条件写法见 conditions.md。编号前缀 F。
# 天府所在地支与同宫星：子午同武曲、寅申同紫微、辰戌同廉贞；丑未、卯酉、巳亥独坐（卯酉对宫武曲七杀，巳亥对宫紫微七杀，丑未对宫廉贞七杀）。天府坐命，官禄宫必是天相。
# "入庙""庙旺"按排盘程序庙旺表（精成§27）：入庙＝子丑寅未，庙旺＝入庙＋辰午酉戌，卯巳申亥得地，无陷。
#   全书卷三"天府庙子丑未寅辰戌 旺午酉 地卯巳申亥 无陷"，辰戌与程序表不同；书里自己列出地支的一律写成"支="（如精成章内称卯、辰戌入庙，字陆评注称酉宫落陷）。
#   程序表无陷，书里只泛称"陷地""失陷"而没有列地支的句子未录。
# 百官：天府坐命必会天相，天府本身不算自己的百官，故本表"百官/非百官"判断时不计"府相"一对（composer.js 已按此处理）。
# 紫府（寅申）、武府（子午）、廉府（辰戌）的规则另见紫微、武曲、廉贞表，网页会同时显示，本表不搬入；本表只录各书在天府段落里说到这三组的话。
# "加煞""见煞""四煞"写成"煞"；"煞忌"写成"煞＆化忌"；"空劫"写成"会:地空/地劫"；"空亡"写成"会:旬空/截空"；"空劫空亡"拆成两条；"粒把煞星""一二煞星"写成"煞少"；"煞多""煞重"写成"煞多"（用户门槛）。
# "限运""流年""大限""二限"内容未录；他宫（夫妻、子女、田宅等）的论断未录；令东来各节里讲他宫四化的句子，只录对命主本人的论断。
# 书间不一的地方照录、不合并：如日月夹命，精成说丑宫较未宫好，南北派说丑宫日月相夹陷地、未必有助。
# 天府制煞拆成条件：三方四正（含命宫）见羊陀火铃（条件"煞"）时才输出制煞的话。两说分开输出、不互相覆盖：
#   精成、全书卷一、令东来、字全书说天府本身能制羊陀、化火铃（F004a、F006a、F202a、F507、F812a）；
#   听课笔记说"不可解厄制化"，须有三台八座才可（F822 不见三台八座、F823 见三台八座）。两说并见时，听课笔记一方标"说法相反"。
# 命盘上不可能成立的组合未录：天府三方四正永不见太阳、天梁，故精成、字全2"与太阳昌曲会，必登甲第/首选"本命未录（全书卷一原文只作"与昌曲会，必登首选"，照录 F205）；精成、字全2这两句原书都放在天府组合喜忌里讲，没有说是限运，只因本命结构不成立暂置表末"限运（暂不触发）"一节；南北派"天梁天府入命"天府、天梁不能同宫，原文也没交代指哪种宫位关系，属结构不可成立、待考，不录也不放限运节；天府三方四正只会紫微、武曲、廉贞、天相、七杀，生年科权禄不可能三方会齐，故"三奇"诸条未录，巳亥宫三方四正不会见化禄，"巳亥加会化禄"未录（禄存仍录）。
