# 本表所有规则的隐含前提：命宫主星有武曲。条件写法见 conditions.md。
# 武曲所在地支与同宫星：子午同天府、丑未同贪狼、寅申同天相、卯酉同七杀、辰戌独坐（对宫贪狼）、巳亥同破军。
# "庙旺""入庙"按排盘程序庙旺表（精成§27）：入庙＝辰戌丑未，庙旺＝入庙＋子午，寅申得地，卯酉利，巳亥平。全书卷三"武曲庙辰戌丑未 旺子午 平巳亥 无失陷"，相同。
# 按程序表与全书卷三，武曲没有落陷之地，所以书里只说"陷地""落陷"而不列地支的句子未录（程序永远不会成立）。
# 书里自己列出陷地的，按该书地支写成"支="：字陆"武曲命宫，在卯落陷"＝支=卯；令东来"武曲在卯宫、酉宫均为落陷"＝支=卯/酉。
# 闲宫：全书卷二"武曲在申为闲宫"；精成、字全2把巳亥称闲宫。按各书自己的说法写"支="。
# "西北生人""东南生人""乱世""富裕家庭"等出生地、家境条件，命盘上读不出，未录；"二限""流年""太岁"等行限内容未录。
# 南北派原文中带"爻"字的半句（疑为"陷"字识别错误）一律未录；"◎"（疑为"庙"）只在书里自己注明地支时按地支录。
