# 格式：编号 | 条件（＆连接，—=无附加条件） | 主题 | 结论（拆成最小单位，用／分开；"主题:"前缀=该条结论另归主题） | 原文 | 来源
# 本表所有规则的隐含前提：命宫主星有巨门。条件写法见 conditions.md。编号前缀 Q。
# 巨门所在地支与同宫星：寅申同太阳、卯酉同天机、丑未同天同；子午独坐（对宫天机）、辰戌独坐（对宫天同）、巳亥独坐（对宫太阳）。
#   巨门坐命，三方四正只会见太阳、天机、天同（及同宫星），永不见紫微、天府、天相、天梁、七杀、破军、贪狼、武曲、廉贞。
#   太阳位置随巨门而定：巨门子→太阳辰（旺）、午→戌（陷）、辰→子（陷）、戌→午（庙）、巳→亥（陷）、亥→巳（旺）、寅申同宫；卯酉丑未三方不见太阳。
#   故书中"会庙旺的太阳"写成 支=子/戌/亥/寅，"太阳陷地"写成 支=午/辰/巳；"庙旺的太阳同宫或对照"写成 支=寅/亥。
# "入庙""庙旺"按排盘程序庙旺表（精成§27）：入庙＝寅卯申酉，庙旺＝入庙＋子午亥；巳为平，辰戌未为平，丑为不得地；程序表无陷。
#   【庙旺表差异，两说并存】巳亥宫程序表作平、书作旺，不改程序表，书自列地支的按"支="照录。
#   书间不一：全书卷三"庙寅申卯酉 旺子午巳亥 陷辰戌"、精成"巳亥宫旺"、令东来"巳亥入庙"，巳宫程序作平、书作旺；书里自己列出地支的一律写成"支="。
#   书里的"陷地""落陷"（巨门独坐时）一律写成 支=辰/戌（【原文】各书明说陷在辰戌，不是程序推断）：全书卷三"陷辰戌"，精成"巨门最忌入陷地，除辛年生人守于辰戍宫较吉外"，字全2辰戌宫标"巨门—陷"，令东来"巨门在辰宫、戌宫为落陷"。
#   "不入庙"（全书卷二）写成 支=子/午/辰/戌/巳/亥/丑/未；"四墓"＝支=辰/戌/丑/未；"水乡"＝支=亥/子。
# 机巨（卯酉）、阳巨（寅申）、同巨（丑未）的规则另见天机、太阳、天同表，网页会同时显示，本表不搬入；本表只录各书在巨门段落里说到这三组的话。
# "石中隐玉"按精成定义：巨门坐命子午，无煞且有科权禄之一在三方四正（禄存同宫亦算），写成 支=子/午＆无煞＆会化:禄/权/科，或 支=子/午＆无煞＆同宫:禄存（编号加b）。
# "限运""流年""大限""入限诀"内容未录；他宫（兄弟、夫妻、子女、财帛、疾厄、迁移、田宅、福德等）巨门的论断未录。
# "吉少""无吉守照"写成"无吉"；"吉多""吉星多"写成"吉多"；"煞重""煞聚""煞星太多"写成"煞多"；"科权禄会齐"写成"三奇"。
# "空劫"写成"会:地空/地劫"；"天空"按书原字写成天空（程序有天空一星）；精成"白虎、贯索、官符"、"大耗"、"丧门"程序均有。
# 南北派"爻"字句（疑为"陷"误识）照前例跳过：巨门爻是非更是利害、女命巨门爻、加四殺爻凶。
# 【结构不可能，未录】（已用排盘程序穷举 262,980 盘验证，巨门坐命 21,918 盘）巨门三方永不见紫微、七杀、贪狼、破军（会紫微或七杀 0 盘），故全书卷一"遇帝座则制其强""逢七杀则主杀伤""贪耗同行"，精成"喜遇紫微禄存来解救"只录禄存一半，

#   巨门不化科（十干四化无巨门化科，0 盘），精成"逢化科"一段、字陆"化权更见化科"未录；子午宫辛年必见羊陀、三奇不可能，精成"石中隐玉化禄主富、科权禄会齐"未录；
#   白虎与贯索不会同在三方四正（岁前十二神里两星相差五宫，0 盘；程序的"官符"含博士十二神的官府，官符与贯索倒是可以同会），精成"白虎、贯索、官符会齐"、南北派"再加贯索"未录；戊壬年天马只在寅申，令东来巳亥宫"戊年、壬年命迁线有天马"未录；
#   癸年天钺在巳，巳亥宫必见吉，令东来"癸年见吉星少"未录。
#   擎羊不入巳亥：精成、南北派"巳亥化权见陀罗"照录，无擎羊同宫之说。
# 字全2"紫微在某宫"诸盘各宫一节中，巨门子、午、辰、戌、巳、亥六宫照录（其余是同宫双星）。
# 书间不一照录：巨门五行，精成、全书卷一、字3、令东来作阴水（金），字陆作阴土阴金；"至亥寅巳申（全书卷一）／亥子丑寅巳申（字全2）虽富贵亦不耐久"；
