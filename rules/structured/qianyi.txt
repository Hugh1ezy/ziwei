# 格式：编号 | 条件（＆连接，—=无附加条件） | 主题 | 结论（用／分开；"主题:"前缀=另归主题） | 原文 | 来源
# 原文栏写"＝"表示结论就是原文，只按句拆开、未改字。编号前缀 D。
# 本表的"本宫"＝迁移宫：同宫＝迁移宫本宫；会＝迁移宫的三方四正（迁移、夫妻、福德、命宫）；夹＝迁移宫两邻宫；对宫＝命宫；支＝迁移宫地支。
#   星=X：迁移宫主星有X（每条规则的前提）。迁移宫无主星时，照旧借对宫主星（程序原有做法），此时同宫、支按对宫算。
#   宫:命宫=X：命宫（真正的命宫）本宫有X。
#   【程序事实】迁移宫与命宫的三方四正是同一组四宫，所以书里"命迁加煞""命迁加会六吉""命迁宫无煞"直接写成 煞、吉、无煞。
#   【新增条件写法】命迁:X＝命宫或迁移宫本宫有X（"命迁宫逢昌陀铃"只看这两宫）；身宫在本宫＝身宫就是迁移宫（太阴"若身宫在此"）。
# 主题：迁移（出外、迁动、在外遭遇）、事业、财富、才能、健康、婚姻、性格、六亲。
# 来源：目前只录《紫微斗数精成》·X星在迁移宫各段，其他书迁移宫的说法待以后补，书间不一再两说并存。

#   "加吉""见吉"写成"吉"；"无吉"写成"无吉"；"加煞""见煞""四煞"写成"煞"；"六煞"写成"会:六煞"；"煞忌"写成"煞＆化忌"；

#   "桃花星"按"桃花"组；"庙旺""失陷"按程序庙旺表（《紫微斗数精成》§27），书自列地支的写成"支="；巨门陷地写成支=辰/戌（同巨门命宫表）。
#   "化禄""化忌"等写在某星段内、未说是谁化的，指该星本身化；同宫两星都可能化的写成 化:甲/乙=X。
#   凶星连写不带"等"字的（"空劫刑忌""煞刑耗忌""虚耗月病符"）各类都要见到，成对之星（空劫、火铃、羊陀、丧吊）见其一即算；带"等"字的见其一即算；吉星连写见其一即算。
